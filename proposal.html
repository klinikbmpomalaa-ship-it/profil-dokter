# 📖 FlipBook Studio Aplikasi web untuk menampilkan dokumen PDF sebagai buku digital dengan animasi balik halaman yang realistis — mirip FlipHTML5. ## ✨ Fitur - 📄 Upload PDF langsung di browser (tidak perlu server) - 🎬 Animasi flip halaman 3D yang halus - 🔍 Zoom in/out (50% – 180%) - 🖼️ Thumbnail strip navigasi cepat - ⌨️ Navigasi keyboard (← →) - ⛶ Mode layar penuh (fullscreen) - 📱 Responsif di mobile - 🔒 100% client-side — PDF tidak dikirim ke server manapun ## 🚀 Hosting di GitHub Pages ### Langkah 1 — Buat Repository 1. Login ke [github.com](https://github.com) 2. Klik **New repository** 3. Beri nama, misal: `flipbook-studio` 4. Centang **"Add a README file"** → klik **Create repository** ### Langkah 2 — Upload File 1. Di halaman repository, klik **Add file → Upload files** 2. Upload file `index.html` ini 3. Klik **Commit changes** ### Langkah 3 — Aktifkan GitHub Pages 1. Buka **Settings** repository 2. Scroll ke bagian **Pages** (sidebar kiri) 3. Di **Source**, pilih branch `main` dan folder `/ (root)` 4. Klik **Save** 5. Tunggu 1–2 menit, lalu akses di: ``` https://USERNAME.github.io/NAMA-REPO/ ``` ## 📁 Struktur File ``` flipbook-studio/ └── index.html ← satu file, semua sudah terintegrasi ``` ## 🛠️ Teknologi - **PDF.js** (Mozilla) — untuk membaca & merender PDF - **Vanilla JS + CSS** — animasi flip 3D murni tanpa library tambahan - **HTML5 Canvas** — rendering halaman berkualitas tinggi ## 📝 Lisensi MIT — bebas digunakan dan dimodifikasi.
